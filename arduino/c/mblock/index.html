برمجة بالمكعبات الملوّنة مثل Scratch: تسحب المكعب وتركّبه، والروبوت يتحرّك!

mBlock برنامج برمجة مرئية: نسحب الكتل الملوّنة ونرتّبها لبناء الخوارزميات بدون أخطاء كتابة. يترجم الكتل لحظياً إلى C/C++ فيفهم المتعلّم العلاقة بين الكتل والكود. يدعم Arduino Uno وNano وMega وmicro:bit وESP32 وmBot.

mBlock برنامج برمجة مرئية: نسحب الكتل الملوّنة ونرتّبها لبناء الخوارزميات بدون أخطاء كتابة. يترجم الكتل لحظياً إلى C/C++ فيفهم المتعلّم العلاقة بين الكتل والكود. يدعم Arduino Uno وNano وMega وmicro:bit وESP32 وmBot.

  • الخطوات: أضف Device ← Arduino Uno
  • اختر وضع Upload (ليس Live)
  • Connect ← اختر المنفذ COM
  • Upload لرفع البرنامج
  • زر </> يعرض كود Arduino المقابل

🖼️الصورة التوضيحية

  • 1
    فئات الكتلPin، Control، Operators…
  • 2
    كتلة البدايةwhen Arduino Uno starts up
  • 3
    foreverمثل loop()
  • 4
    Uploadرفع البرنامج
  • 5
    عرض الكودC/C++

⚙️كيف تعمل؟

  1. ثبّت mBlock 5 وشغّله
  2. Devices ← Add ← Arduino Uno
  3. وصّل الكابل ← Connect ← COM
  4. اسحب الكتل ← Upload

💻البرمجة: Arduino IDE و mBlock 5

void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);  // أشعل
  delay(1000);
  digitalWrite(13, LOW);   // أطفئ
  delay(1000);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
