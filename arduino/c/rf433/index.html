وحدة اتصال لاسلكي تعتمد على موجات الراديو 433MHz. بسيطة ومنخفضة التكلفة، لكنها تحتاج بروتوكول اتصال (مكتبة مثل RadioHead أو RCSwitch). تُستعمل في أنظمة الإنذار والتحكم اللاسلكي.

وحدة اتصال لاسلكي تعتمد على موجات الراديو 433MHz. بسيطة ومنخفضة التكلفة، لكنها تحتاج بروتوكول اتصال (مكتبة مثل RadioHead أو RCSwitch). تُستعمل في أنظمة الإنذار والتحكم اللاسلكي.

  • المرسل FS1000A: 3–12V (جهد أعلى = مدى أطول)
  • المستقبل: 5V
  • هوائي سلك طوله 17.3cm (ربع الطول الموجي)
  • اتصال في اتجاه واحد فقط

💻البرمجة: Arduino IDE و mBlock 5

#include <RCSwitch.h>
RCSwitch tx = RCSwitch();
void setup() { tx.enableTransmit(12); }   // DATA → D12
void loop() {
  tx.send(1234, 24);   // أرسل الرقم 1234
  delay(1000);
}
