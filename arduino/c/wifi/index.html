وحدة تمكّن الأردوينو من الاتصال بشبكة Wi-Fi. ESP8266 اقتصادية، وESP32 تدعم Wi-Fi وBluetooth معاً. تُستعمل في إنترنت الأشياء (IoT) والتحكم عن بعد وإرسال البيانات إلى السحابة.

وحدة تمكّن الأردوينو من الاتصال بشبكة Wi-Fi. ESP8266 اقتصادية، وESP32 تدعم Wi-Fi وBluetooth معاً. تُستعمل في إنترنت الأشياء (IoT) والتحكم عن بعد وإرسال البيانات إلى السحابة.

  • ESP32: ثنائي النواة 240MHz، 520KB RAM
  • منطق 3.3V — لا تدخل 5V على المنافذ
  • Wi-Fi 2.4GHz فقط
  • تُبرمج مباشرة من Arduino IDE (أضف حزمة ESP32)

💻البرمجة: Arduino IDE و mBlock 5

#include <WiFi.h>
void setup() {
  Serial.begin(115200);
  WiFi.begin("MyWiFi", "password");
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print('.'); }
  Serial.println(WiFi.localIP());
}
void loop() {}

Wi-Fi على ESP32 يُبرمج من Arduino IDE (أو من mBlock بعد إضافة جهاز ESP32).
