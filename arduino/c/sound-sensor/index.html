مستشعر يكتشف شدة الصوت باستعمال ميكروفون. يُستعمل في روبوتات تتفاعل مع التصفيق وأنظمة التحكم الصوتي البسيطة.

مستشعر يكتشف شدة الصوت باستعمال ميكروفون. يُستعمل في روبوتات تتفاعل مع التصفيق وأنظمة التحكم الصوتي البسيطة.

  • ميكروفون مكثّف (Electret) + مقارن LM393
  • AO: شدة الصوت، وDO: تجاوز العتبة
  • لا يتعرّف على الكلام — يقيس الشدة فقط

💻البرمجة: Arduino IDE و mBlock 5

bool on = false;
void setup() { pinMode(2, INPUT); pinMode(13, OUTPUT); }
void loop() {
  if (digitalRead(2) == HIGH) {   // تصفيقة
    on = !on; digitalWrite(13, on);
    delay(300);
  }
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
