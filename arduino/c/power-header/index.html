🧒
محطة الكهرباء في الأردوينو: منها نأخذ الطاقة للحساسات.

IOREF: يحدد جهد عمل اللوحة (5V) لمساعدة الشيلدات. RESET: إعادة التشغيل عند وصله بـ GND. 3.3V: خرج لتغذية المكونات التي تعمل بهذا الجهد. 5V: خرج لتغذية معظم الحساسات. GND: الأرضي (0V) لإكمال الدائرة. VIN: مدخل لجهد خارجي 7–12V، أو خرج لنفس جهد المقبس.

IOREF: يحدد جهد عمل اللوحة (5V) لمساعدة الشيلدات. RESET: إعادة التشغيل عند وصله بـ GND. 3.3V: خرج لتغذية المكونات التي تعمل بهذا الجهد. 5V: خرج لتغذية معظم الحساسات. GND: الأرضي (0V) لإكمال الدائرة. VIN: مدخل لجهد خارجي 7–12V، أو خرج لنفس جهد المقبس.

  • 5V: حتى حوالي 400–500mA عند التغذية بالـ USB
  • 3.3V: تيار حتى 150mA تقريباً
  • كل GND متصلة ببعضها
  • VIN = جهد المقبس ناقص ~0.7V (الدايود)

📍 مكانها على لوحة Arduino UNO

💻البرمجة: Arduino IDE و mBlock 5

// اقرأ جهد 3.3V بعد توصيله بـ A0
void setup() { Serial.begin(9600); }
void loop() {
  float v = analogRead(A0) * 5.0 / 1023.0;
  Serial.println(v);   // ≈ 3.30
  delay(500);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
