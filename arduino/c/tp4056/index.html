📖الشرح حسب العمر

🧒
لوحة صغيرة تشحن بطارية الليثيوم من شاحن الهاتف بأمان.

TP4056 يشحن بطاريات Li-ion عبر USB. BMS يحمي البطارية من الشحن الزائد والتفريغ المفرط. DC-DC Converter يحوّل الجهد إلى 5V أو 3.3V. اختر البطارية حسب مدة التشغيل وحجم المشروع، واستعمل BMS مع الليثيوم، وتأكد من توافق الجهد.

TP4056 يشحن بطاريات Li-ion عبر USB. BMS يحمي البطارية من الشحن الزائد والتفريغ المفرط. DC-DC Converter يحوّل الجهد إلى 5V أو 3.3V. اختر البطارية حسب مدة التشغيل وحجم المشروع، واستعمل BMS مع الليثيوم، وتأكد من توافق الجهد.

  • طريقة الشحن CC/CV حتى 4.2V
  • تيار الشحن 1A (يُضبط بمقاومة R_PROG = 1.2kΩ)
  • الأحمر = يشحن، والأزرق/الأخضر = اكتمل
  • النسخة مع DW01 + FS8205 تحمي من التفريغ < 2.5V

💻البرمجة: Arduino IDE و mBlock 5

// قياس جهد البطارية عبر مقسّم جهد (10k + 10k) على A0
void setup() { Serial.begin(9600); }
void loop() {
  int raw = analogRead(A0);
  float v = raw * 5.0 / 1023.0 * 2.0;   // ×2 بسبب المقسّم
  Serial.print("Battery: "); Serial.print(v); Serial.println(" V");
  delay(1000);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
