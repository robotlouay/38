🧒
TX يومض عندما يتكلّم الأردوينو، وRX يومض عندما يسمع.

RX يومض عند استقبال بيانات عبر المنفذ التسلسلي Pin 0، وTX يومض عند إرسال بيانات عبر Pin 1. أثناء رفع البرنامج يومضان بسرعة، وهذا دليل على أن البرنامج ينتقل إلى المتحكّم.

RX يومض عند استقبال بيانات عبر المنفذ التسلسلي Pin 0، وTX يومض عند إرسال بيانات عبر Pin 1. أثناء رفع البرنامج يومضان بسرعة، وهذا دليل على أن البرنامج ينتقل إلى المتحكّم.

  • UART بسرعات شائعة 9600 و115200 baud
  • Pin 0 = RX، وPin 1 = TX
  • لا توصل شيئاً على D0/D1 أثناء الرفع

🖼️الصورة التوضيحية

  • 1
    TXTransmit — إرسال
  • 2
    RXReceive — استقبال

📍 مكانها على لوحة Arduino UNO

💻البرمجة: Arduino IDE و mBlock 5

void setup() {
  Serial.begin(9600);
}
void loop() {
  Serial.println("Hello robotlouay!"); // TX يومض
  delay(1000);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
