مستشعر يقيس شدة الإضاءة المحيطة. LDR مقاومة تقل قيمتها كلما زاد الضوء. يُستعمل في أنظمة الإضاءة التلقائية وروبوتات تتبّع الضوء، ويُوصل مع مقاومة 10kΩ كمقسّم جهد على منفذ تناظري.

مستشعر يقيس شدة الإضاءة المحيطة. LDR مقاومة تقل قيمتها كلما زاد الضوء. يُستعمل في أنظمة الإضاءة التلقائية وروبوتات تتبّع الضوء، ويُوصل مع مقاومة 10kΩ كمقسّم جهد على منفذ تناظري.

  • في الظلام ≈ 1MΩ، وفي الضوء ≈ 1kΩ أو أقل
  • مقسّم جهد: LDR + 10kΩ ← A0
  • بطيء نسبياً (عشرات الملي ثانية)

💻البرمجة: Arduino IDE و mBlock 5

void setup() { pinMode(9, OUTPUT); }
void loop() {
  int light = analogRead(A0);
  if (light < 300) digitalWrite(9, HIGH);  // مظلم ← أشعل
  else digitalWrite(9, LOW);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
