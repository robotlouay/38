شيلدات جاهزة لكل شيء: للمحركات، للإنترنت، للشاشة والأزرار.

Motor Shield: لمحركات DC وStepper. Ethernet Shield: شبكة عبر كابل LAN. LCD Keypad Shield: شاشة بأزرار. Sensor Shield: لتوصيل حساسات كثيرة بسهولة. Wave Shield: تشغيل WAV. Proto Shield: لبناء دوائرك الخاصة. المميزات: سهولة التركيب، توفير الوقت، التوسّع، والتوافق.

  • Sensor Shield V5: كل منفذ له G وV وS
  • Ethernet Shield W5100 يستعمل SPI + منفذ microSD
  • LCD Keypad: الأزرار كلها على A0 بمقسّم جهد
