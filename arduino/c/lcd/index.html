📖الشرح حسب العمر

🧒
شاشة صغيرة تكتب عليها كلمات وأرقام، مثل شاشة الآلة الحاسبة.

تعتمد على البلورات السائلة لعرض النصوص والأرقام. أشهر الأنواع LCD 16×2 (16 حرفاً × سطران) وLCD 20×4. توصيلها عبر وحدة I2C يقلّل الأسلاك إلى 4 فقط. تُستعمل لعرض الرسائل وقراءات الحساسات.

تعتمد على البلورات السائلة لعرض النصوص والأرقام. أشهر الأنواع LCD 16×2 (16 حرفاً × سطران) وLCD 20×4. توصيلها عبر وحدة I2C يقلّل الأسلاك إلى 4 فقط. تُستعمل لعرض الرسائل وقراءات الحساسات.

  • المتحكّم HD44780
  • عنوان I2C الشائع 0x27 أو 0x3F
  • مكتبة LiquidCrystal_I2C
  • المقاومة المتغيرة الزرقاء خلف الوحدة تضبط التباين

💻البرمجة: Arduino IDE و mBlock 5

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);
void setup() {
  lcd.init(); lcd.backlight();
  lcd.print("Hello!");
  lcd.setCursor(0, 1);
  lcd.print("@robotlouay");
}
void loop() {}
🧩
شاشة LCD I2C تحتاج إضافة «LCD» من «الإضافات» في mBlock، والأسهل استعمال Arduino IDE.
