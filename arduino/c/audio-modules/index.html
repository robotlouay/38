Wave Shield يشغّل ملفات WAV من بطاقة SD. Arduino Audio Shield لتشغيل ومعالجة الصوت بجودة عالية. MP3 Player Shield يشغّل MP3 مع تحكم (تشغيل/إيقاف/التالي). الأشهر والأرخص اليوم: وحدة DFPlayer Mini تتصل بـ UART وتشغّل سماعة 3W مباشرة.

Wave Shield يشغّل ملفات WAV من بطاقة SD. Arduino Audio Shield لتشغيل ومعالجة الصوت بجودة عالية. MP3 Player Shield يشغّل MP3 مع تحكم (تشغيل/إيقاف/التالي). الأشهر والأرخص اليوم: وحدة DFPlayer Mini تتصل بـ UART وتشغّل سماعة 3W مباشرة.

  • DFPlayer Mini: microSD حتى 32GB، FAT32
  • مضخّم 3W مدمج (SPK1/SPK2)
  • تحكم Serial بسرعة 9600 baud — مكتبة DFRobotDFPlayerMini
  • ضع مقاومة 1kΩ على خط RX

💻البرمجة: Arduino IDE و mBlock 5

#include <SoftwareSerial.h>
#include <DFRobotDFPlayerMini.h>
SoftwareSerial s(10, 11);      // RX, TX
DFRobotDFPlayerMini mp3;
void setup() {
  s.begin(9600);
  mp3.begin(s);
  mp3.volume(20);              // 0..30
  mp3.play(1);                 // 0001.mp3
}
void loop() {}

DFPlayer يحتاج مكتبة — استعمل Arduino IDE، أو أضف إضافة DFPlayer من «الإضافات» في mBlock.
