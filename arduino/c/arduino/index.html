الأردوينو مثل دماغ صغير للروبوت: تكتب له التعليمات، وهو ينفّذها فيُشغّل الأضواء والمحركات.

الأردوينو منصّة إلكترونية مفتوحة المصدر تتكوّن من لوحة فيها متحكّم دقيق (Microcontroller) وبرنامج مجاني (Arduino IDE) نكتب فيه الأوامر بلغة مبنية على C/C++ ثم نرفعها إلى اللوحة. بدأ المشروع سنة 2005 في مدينة إيفريا بإيطاليا على يد ماسيمو بانزي وفريقه، وسُمّي على اسم مقهى «Bar di Re Arduino».

الأردوينو منصّة إلكترونية مفتوحة المصدر تتكوّن من لوحة فيها متحكّم دقيق (Microcontroller) وبرنامج مجاني (Arduino IDE) نكتب فيه الأوامر بلغة مبنية على C/C++ ثم نرفعها إلى اللوحة. بدأ المشروع سنة 2005 في مدينة إيفريا بإيطاليا على يد ماسيمو بانزي وفريقه، وسُمّي على اسم مقهى «Bar di Re Arduino».

  • مفتوح المصدر: مخططات اللوحة والبرنامج متاحة للجميع
  • اللغة: Arduino C/C++ فوق مترجم avr-gcc
  • الاستعمالات: التعليم، الروبوتات، إنترنت الأشياء IoT، الأتمتة
  • يعمل على Windows وmacOS وLinux

⚙️كيف تعمل؟

  1. تكتب البرنامج في Arduino IDE أو mBlock
  2. توصل اللوحة بالحاسوب عبر USB وترفع البرنامج
  3. المتحكّم يقرأ الحساسات وينفّذ الأوامر
  4. تتحرّك المحركات وتضيء الأضواء حسب برنامجك

💻البرمجة: Arduino IDE و mBlock 5

void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);  // أشعل
  delay(1000);
  digitalWrite(13, LOW);   // أطفئ
  delay(1000);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
