بطاريات نشحنها ونستعملها مرات كثيرة؛ الليثيوم خفيفة وقوية لذلك نجدها في الهواتف.

بطاريات NiMH: جهد 1.2V للخلية وتُشحن مئات المرات، لكن تفريغها الذاتي سريع نسبياً. بطاريات الليثيوم (Li-ion / Li-Po): 3.7V للخلية، سعة عالية، وزن خفيف، مثالية للروبوتات والدرون، لكنها تحتاج دائرة حماية.

بطاريات NiMH: جهد 1.2V للخلية وتُشحن مئات المرات، لكن تفريغها الذاتي سريع نسبياً. بطاريات الليثيوم (Li-ion / Li-Po): 3.7V للخلية، سعة عالية، وزن خفيف، مثالية للروبوتات والدرون، لكنها تحتاج دائرة حماية.

  • Li-ion: مشحونة 4.2V، فارغة ≈ 3.0V
  • 18650: سعة ≈ 2000–3500mAh
  • 2S = 7.4V (مناسب لـ VIN)
  • معدل C للـ LiPo: 20C × 1Ah = 20A

💻البرمجة: Arduino IDE و mBlock 5

// قياس جهد البطارية عبر مقسّم جهد (10k + 10k) على A0
void setup() { Serial.begin(9600); }
void loop() {
  int raw = analogRead(A0);
  float v = raw * 5.0 / 1023.0 * 2.0;   // ×2 بسبب المقسّم
  Serial.print("Battery: "); Serial.print(v); Serial.println(" V");
  delay(1000);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
