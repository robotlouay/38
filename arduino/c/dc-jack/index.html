يُستعمل مقبس الطاقة لتشغيل الأردوينو من مصدر خارجي. نوعه 2.1×5.5mm والقطب الموجب في الوسط. الجهد الموصى به 7–12V (الحدود 6–20V). يمر الجهد عبر دايود حماية ثم منظّم الجهد. عند توصيل USB والمقبس معاً تختار اللوحة المقبس تلقائياً إذا كان جهده أعلى من 6.6V تقريباً.

يُستعمل مقبس الطاقة لتشغيل الأردوينو من مصدر خارجي. نوعه 2.1×5.5mm والقطب الموجب في الوسط. الجهد الموصى به 7–12V (الحدود 6–20V). يمر الجهد عبر دايود حماية ثم منظّم الجهد. عند توصيل USB والمقبس معاً تختار اللوحة المقبس تلقائياً إذا كان جهده أعلى من 6.6V تقريباً.

  • قطر داخلي 2.1mm وخارجي 5.5mm
  • القطب الموجب في المركز (Center positive)
  • دايود M7 يحمي من عكس القطبية
  • 9V بطارية = عمر قصير؛ الأفضل محوّل 9V/1A

🖼️الصورة التوضيحية

  • 1

  • 2
    الطرف الأوسط +القطب الموجب
  • 3
    أرجل اللحامتتصل بالدايود والمنظّم
  • 4
    رمز القطبيةالموجب في الوسط

📍 مكانها على لوحة Arduino UNO

💻البرمجة: Arduino IDE و mBlock 5

void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);  // أشعل
  delay(1000);
  digitalWrite(13, LOW);   // أطفئ
  delay(1000);
}

في mBlock 5: الأجهزة ← أضف ← Arduino Uno، اختر وضع رفع (Upload)، ثم اتصال واختر منفذ COM، ركّب الكتل كما في الصورة واضغط رفع.
